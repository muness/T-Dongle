# The transport contract of the controller: every command form, and which transports serve it.
#
# One dispatcher (rust/firmware/src/main.rs `handle`) serves both transports. Web Serial types the line into the CDC-ACM
# console; HTTP POSTs the same line to /serial (tailnet mode, 192.168.77.1), and tdongle_setup::usb::command_allowed decides
# whether it reaches the dispatcher. Reply bytes are the same either way.
#
# Format: KIND | PATTERN | EXEMPLAR | NOTE
#   both    served over Web Serial and POST /serial: same dispatcher, same reply bytes
#   serial  console only: POST /serial answers 403 "That command is not available here"
#   absent  not a command on any transport (the dispatcher replies "unknown"); listed so adding one forces a decision here
# PATTERN is a JavaScript regex (whole line) the web UI's sent lines are matched against.
# EXEMPLAR is one concrete line; the Rust test (tdongle-setup/tests/webui_contract.rs) and rust/webui/test.mjs both run it.
#
# Checked by: cargo test -p tdongle-setup --test webui_contract, and node rust/webui/test.mjs.
