T-Dongle setup

Connect your dongle to Wi-Fi

About a minute. Forwarding and tailnets are paused while this page is open.

  1. Pick the 2.4 GHz network the dongle should use
  2. Save it. Add more networks the same way if you like
  3. Tap Done; the dongle restarts and joins the best one it can find
Advanced: slot
A network is saved on the dongle as soon as you tap Save. This page can add and delete networks; names, priorities and changing a saved network are done from the dongle's button menu, USB or the app. Nothing here checks that the network reaches the Internet. Setup closes by itself after 10 minutes.
