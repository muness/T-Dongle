# Execute: control-path repair and recoverable diagnostics

**Aim:** Make valid tailnet control traffic survive packet timing, preserve setup capacity, and retain enough failure evidence to investigate after Android disconnects from USB.

**Selected approach:** B from [the dissent/solution-space handoff](control-path-dissent-2026-10-01.md). Preserve the original no-PSRAM board, NVS partition/identities, independent 0/1/n saved memberships, existing ACK correction, automatic Android archive and integration branches. No board flash, production release or merge is authorized in this session.

**Success criteria:** Length-driven HTTP/Noise/EarlyNoise/H2 boundaries with bounded storage and explicit fatal errors; real local HTTP/2 interoperability; reserved management/DNS descriptors plus heap admission; precise persisted startup/protocol/socket evidence; single Android diagnostic collector with cached reports and retained successful evidence after failures/detach; passing meaningful regression/build checks; an installable APK with the updated alternative firmware.

## Review

**Status:** Continue to packaging/delivery. The selected frame still explains reproduced framing and descriptor defects. It does not establish the cause of every photographed management error.

The production reader now reads headers through their terminator and exact records through their declared lengths, advances nonces only after authenticated decrypt, and retains only bounded per-session plaintext tails. Startup allocations are bounded and released before registration. Shared map/registration workspace remains mutex protected. Both resource admission and HTTP session limits reserve recovery service capacity; simply increasing the descriptor total would not pass the admission tests. Review found IPv6 STUN retention, so the final budget includes that descriptor and each membership's transient allocation. Review also repaired a stale Android API-29-only MTU call so diagnostics remain valid on minSdk 26.

No new architecture decision or broader UI redesign was introduced. The original framing tests, socket model and test stubs were insufficient and have been replaced or expanded. The sg CLI is unavailable; this review inspected the actual diffs, callers, response tails, NVS migration, linker wrappers and Android lifecycle/report paths. No independent CodeRabbit or physical review is claimed.
