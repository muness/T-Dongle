# Gateway preview validation

The actual gateway builds for the original no-PSRAM ESP32-S3 with pinned ESP-IDF v5.5.5. This supersedes the earlier unused-runtime audit binary. `tools/build-gateway.sh` packages only bootloader, partition table and app at 0x0, 0x8000 and 0x20000; the existing 0x9000–0x19000 NVS region is preserved. The normal bridge source has not changed.

`tools/test-gateway.sh` runs the actual router, map reader and identity-loading function under ASan/UBSan. Router cases cover zero memberships, three identical peer addresses, wrong-identity replies, forged USB sources, unsolicited flows, fragments, checksums, independent suspend/remove, stable suspended aliases, USB-generation invalidation, expired flows and 10,000 malformed packet inputs. Stream cases cover 40 Noise chunk sizes, fragmented/coalesced maps, map boundaries spanning HTTP/2 frames, empty initial responses, SETTINGS acknowledgement, oversized length prefixes, padding rejection and incomplete-message failure. Identity cases cover independent three-member keys, restart, failed namespace opening and failed commit without claiming persistent identity.

Fresh manual diff review covered ownership during shutdown, memory admission, separate NVS/UDP/discovery state, DHCP-before-start configuration, setup-service ingress restrictions and token redaction in Android diagnostics. The sg CLI is unavailable. The companion core and Android unit suites pass; the APK uses the same signing certificate and Open Horizon Labs application ID as installed version 92. No CodeRabbit success or physical test is claimed.

Remaining device checks: USB DHCP/Android network selection; real browser and auth-key enrollment; saved identities after replug; two simultaneously useful tailnets with overlapping addresses and names; direct and DERP-only TCP/UDP traffic; low-memory admission without disrupting existing traffic; independent remove/reconnect; Wi-Fi and USB recovery; extended stability and useful throughput. Issue 41 and the qualification-dependent checks in 35–40 remain open. This preview is an installable implementation, not a qualified release.
